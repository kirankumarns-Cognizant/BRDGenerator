# Gap Analysis Skill

## Overview
Compares documented requirements with actual code implementation to identify gaps and inconsistencies.

## Capabilities
- Gap identification
- Consistency checking
- Coverage analysis
- Undocumented feature detection
- Discrepancy reporting

## When to Use
- Comparing specs to code
- Identifying missing features
- Finding inconsistencies
- Coverage assessment

## Usage
```
"Compare the specification with the code and identify gaps"
```
