# Quality Validation Skill

## Overview
Validates generated BRD documents for completeness, consistency, and adherence to quality standards.

## Capabilities
- Completeness checking
- Consistency validation
- Cross-reference verification
- Quality scoring
- Issue identification

## When to Use
- Before BRD finalization
- Quality assurance
- Document review
- Handoff preparation

## Usage
```
"Validate the BRD for completeness and consistency"
```
